# Simple Calculator Project

## 🧠 What is this project?
This is a basic **calculator built with HTML, CSS, and JavaScript**. It allows students to apply and demonstrate their understanding of **DOM manipulation**, **event handling**, and **basic logic flow** in JavaScript.

## 🎯 Learning Objectives
- Understand how to **select and interact** with DOM elements
- Learn how to **attach event listeners** to multiple elements
- Practice **string concatenation** and handling **mathematical evaluation**
- Get experience writing **reusable JavaScript logic**

## 🛠 How It Works
- The calculator has an input field that displays the current expression
- Each button click appends a value to the input
- The equals button (`=`) evaluates the string using JavaScript’s `eval()` function
- The clear button (`C`) resets the display

## 🧩 Why This Matters
- **DOM manipulation** is a fundamental skill in front-end development
- This project gives students a working example of how **real user input** can be captured and used to perform actions
- The use of string-building, conditionals, and basic layout styles lays a foundation for more complex web apps

## ✨ Extension Ideas
- Add keyboard support (so users can type numbers)
- Prevent multiple operators from being entered consecutively
- Add support for parentheses
- Style the calculator with a theme switcher (dark/light mode)

## 🗃 Files Included
- `index.html` – Structure of the calculator
- `style.css` – Styling for the layout and buttons
- `script.js` – Logic for handling inputs, clearing, and calculating

## ✅ What’s Next?
Once you've completed and understood this project, try modifying it or adding your own features! This is a great portfolio project to showcase your JavaScript and DOM skills.

Happy coding! 🎉
